# EcoVision AI — Smart Waste Analytics System

EcoVision AI is an enterprise-grade Java-based web application built to address municipal solid waste management challenges. By processing IoT fill levels and automated waste stream metrics, the platform optimizes collection schedules and alerts operators to critical overflows.

## Features
- **Real-Time Data Telemetry:** Live capacity tracking across municipal nodes.
- **Rule-Engine Prioritization:** Dynamic status classification (`NORMAL`, `WARNING`, `CRITICAL`).
- **Responsive Dashboard UI:** Styled with Tailwind CSS for visual clarity.

## Technologies Used
- **Backend:** Java 17, Spring Boot 3, Spring Data JPA
- **Database:** In-Memory H2 Database
- **Frontend:** Thymeleaf, HTML5, Tailwind CSS
- **Build Tool:** Maven
